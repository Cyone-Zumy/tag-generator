## 项目简介

本工具用于设计并生成「词条选择器」页面。你只需在编辑界面中逐条录入词条与规则，
工具会实时渲染预览，并输出一份独立可运行、无需任何依赖的 HTML 文件。

整个项目是**单个 HTML 文件**，不依赖 Node.js、不依赖构建工具，也不需要联网。

## 功能特性

### 词条与层级
- 词条编号支持 `1`、`1.1`、`1.1.1` 等写法，自动识别父子关系
- 每个词条可设置名称、描述、图标、额外父词条（多个用英文逗号分隔）
- 父连线可逐个配置：每个父词条单独设置出发边 / 终止边

### 分数系统
- **静态分数**：从词条描述末尾自动提取，也可手动覆盖
- **动态分数**：勾选后忽略静态分数，按当前难度 `x` 计算
  `5x + (max{x-10, 0})²`
- 初始难度可设为 `0 ~ 18`，在生成的选择器中仍可继续调整

### 冲突组
- 同一父节点下、冲突组相同的词条互斥
- 例：`2.1.1`~`2.1.4` 的冲突组均为 `A`、父节点均为 `2.1`，则它们互相冲突

### 视觉定制
- 全局主题色，应用于选中词条的连线、冲突标记与二值化图标
- 纹理 / 渐变填充：支持渐变（两种颜色 + 角度）与纹理图片（平铺 / 覆盖），可替换主题色
- 背景设置：词条选择器背景、指标集背景，各自可上传图片并调节透明度
- 图标处理：上传图片自动裁剪为正方形并铺满，词条名称自动反色；可选二值化（黑白，选中时自动反色）

### 布局与输出
- 自定义网格坐标（X, Y）；在预览中选中词条后，可用方向键微调位置
- 实时预览，随时查看效果
- 生成 HTML 代码 / 下载文件，产出物可直接部署或分发

## 快速开始

1. 下载或克隆本仓库
2. 直接用浏览器打开 `index.html`

无需安装任何依赖。如果双击打开出现空白或样式异常（部分浏览器限制本地文件加载），
可在项目目录下启动一个本地静态服务器：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。

## 使用指南

1. **设置初始难度**：拖到 0 ~ 18 之间的目标值
2. **选择主题**：设置全局主题色；如需更丰富效果，启用纹理 / 渐变填充
3. **录入词条**：填写编号、名称、描述、图标、冲突组，决定分数用静态还是动态
4. **调整位置**：设置自定义网格坐标，或在预览中选中后用方向键微调
5. **配置背景**：分别为选择器区域与指标集区域上传背景图并调整透明度
6. **预览与导出**：确认右侧预览无误后，点击「生成 HTML 代码」或「下载文件」

## 浏览器兼容性

项目依赖现代浏览器的 Canvas、File API 等能力，不支持 IE。

## 部署到 GitHub Pages

1. 确保主文件名为 `index.html` 并位于仓库根目录
2. 进入仓库 **Settings → Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选择 `main`，目录选择 `/ (root)`，点击 **Save**
5. 等待 1 ~ 2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 常见问题

**Q：需要安装依赖吗？**
A：不需要，单个 HTML 文件即可运行。

**Q：生成的选择器可以离线使用吗？**
A：可以。产出的 HTML 文件本身不依赖网络。

**Q：上传的图片会传到服务器吗？**
A：不会，所有处理都在浏览器本地完成。

**Q：进度会保存吗？**
A：编辑器为单页应用，建议编辑完成后及时导出 HTML 文件，避免刷新页面导致内容丢失。
